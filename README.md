# Portafolio de Karol Cabrera

Hola, soy **Karol Isabella Cabrera Pantoja**. Este es mi portafolio personal, creado para compartir quién soy, mi formación y experiencia, y algunos de los proyectos en los que he trabajado.

El sitio incluye versiones en español e inglés, tema claro y oscuro, una galería de proyectos con enlaces a sus demos y un formulario de contacto.

## Tecnologías

- Next.js 16 y React 19
- TypeScript
- Tailwind CSS 4 y CSS

## Ejecutar localmente

```bash
npm install
npm run dev
```

Luego abre [http://localhost:3000](http://localhost:3000).
